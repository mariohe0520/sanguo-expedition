# 三国·天命

> 三国主题放置类 RPG — 收集武将、排兵布阵、征战天下

**[立即游玩](https://mariohe0520.github.io/sanguo-expedition/)**

---

## 游戏特色

- **战略编队** — 前排坦克 + 后排输出，兵种相克制造战术深度
- **武将收集** — 50+ 三国名将，N/R/SR/SSR/UR 五档品质
- **放置挂机** — 离线最多 24 小时收益，随时查收资源
- **天命抉择** — 每章关键抉择，影响故事走向
- **竞技场** — 模拟对战，爬升段位赢取周奖励
- **天下地图** — 策略占领各州郡

## 核心玩法

1. **招募武将** → 求贤馆对话拜访 or 标准抽卡
2. **组建阵容** → 前排2 + 后排3，注意兵种克制
3. **征战关卡** → 自动战斗，速度可调 1x/2x/3x
4. **离线挂机** → 关闭游戏后仍持续获得金币和经验
5. **天命抉择** → 每章第5关通关后做出关键抉择

## 技术栈

- 纯原生 JavaScript（无框架，无构建工具）
- HTML5 Canvas 战斗渲染
- CSS3 动画
- LocalStorage 存档
- PWA（可安装到主屏幕）

## 目录结构

```
js/
├── config/     # 数据配置（武将/关卡/装备/数值参数）
├── core/       # 核心引擎（战斗/存档/离线收益）
├── systems/    # 游戏系统（抽卡/竞技场/副本/装备）
├── ui/         # 界面渲染（战斗动画/特效/音效）
├── extras/     # 扩展功能（个性/剧情/地图）
└── app.js      # 主入口
```
